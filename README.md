# Executive Sales & Profit Dashboard

This project presents an **Executive Sales & Profit Dashboard** built using **Excel, Power Query, Power Pivot, and DAX** to analyze sales performance and profitability.

## Data Model
A relational data model was created in **Power Pivot** by connecting the following tables:

- Sales
- Product
- Customer

The tables were linked using **One-to-Many relationships** to ensure accurate analysis and enable advanced metrics.

## DAX Measures
Several key measures were created using **DAX**, including:

- Total Sales
- Total Profit
- Average Unit Price
- Gross Profit Margin %

## KPI Indicator
A **KPI indicator** was implemented to track **Total Profit against a target of $100,000**, with defined performance thresholds to evaluate performance levels.

## Dashboard Features
The dashboard allows interactive analysis of:

- Product Category
- Sales Channel
- Country
- Year

Users can apply filters to explore the data dynamically and gain insights that support **data-driven decision making**.

## Tools Used
- Power Pi
- Excel
- Power Query
